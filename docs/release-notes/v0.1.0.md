# OpenDroneLab 0.1.0 release notes (draft)

**Status:** prepared, **not published**. There is no `v0.1.0` git tag
and no GitHub Release yet. This document is ready for maintainer
review.

Date on the draft cut: 2026-11-14. Sample assets prepared: 2026-11-17.
First-party license: AGPL-3.0-only. The verified path is
software-in-the-loop. OpenDroneLab is **not flight-certified**.

## Highlights

- Simulation-first stack in one development image: PX4 v1.17 SITL,
  ROS 2 Jazzy, Gazebo Harmonic, a C++ OFFBOARD square-flight mission,
  and optional OpenVINS (GPL-3, isolated).
- Official evo Umeyama regression gates for `baseline`,
  `faster_motion`, `wind`, and `mc_gps`. `low_texture` is scored but
  non-gating. Scenario fingerprints and pass@1 reporting are in place.
- Report-only VIO pose-jump detector. Opt-in raw camera and OpenVINS
  feature recording (`RECORD_CAMERA=1`, `RECORD_OV_FEATURES=1`).
- Harmony CLA in force, CODEOWNERS, CI (headless unit tests,
  ShellCheck, actionlint), issue forms, and a public roadmap.

## Documented benchmark numbers

These are real SITL results already recorded in the README. Gates live
in `config/regression_thresholds.yaml` and must not be loosened.

| Scenario | Official metric | Gate (m) | Documented result |
|----------|-----------------|----------|-------------------|
| `mc_gps` | EKF2 Umeyama xy | 0.39 | N=5 on 2026-11-13: mean 0.2572 ± 0.0022 m, pass@1 5/5 |
| `baseline` | VIO / EKF2 Umeyama xy | VIO 0.70, EKF2 0.40 | 2026-11-13 check: EKF2 xy 0.258 m, VIO xy 0.445 m |
| `faster_motion` | VIO Umeyama xy | 0.42 | Gate from the 2026-11-09 calibration |
| `wind` | VIO Umeyama xy | 1.85 | Gate from the 2026-11-09 calibration |

`fw_mission` (`gz_rc_cessna`) is opt-in and has no official gate yet.

## Known limitations

- Baseline OpenVINS can still jump on the far side of the 10 m square
  (ODL-86). A later diagnostic flight failed the 0.70 m VIO gate
  (0.9716 m). The gate stays. See [ROADMAP.md](../../ROADMAP.md).
- `low_texture` is a known, non-gating limitation.
- No published GHCR image yet. No `./odl` wrapper. Hardware bring-up
  is deferred; SITL numbers are not a flight certification.
