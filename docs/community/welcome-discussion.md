# Welcome to OpenDroneLab

> This post was published as [Discussion #32](https://github.com/palcode/opendronelab/discussions/32) in the Announcements category.

Hello, and welcome to OpenDroneLab.

OpenDroneLab is a scored, sim-first lab: PX4 v1.17, ROS 2 Jazzy, and Gazebo Harmonic in one development image, with official evo Umeyama RMSE gates on software-in-the-loop flights. The verified path today is SITL. **This project is not flight-certified.** Please do not use it to operate a real aircraft without a separate safety, legal, and range review.

## Where to start

- Read the [README](https://github.com/palcode/opendronelab#readme) and [ROADMAP.md](https://github.com/palcode/opendronelab/blob/main/ROADMAP.md).
- New contributors: pick up a [good first issue](https://github.com/palcode/opendronelab/labels/good%20first%20issue). Please use the issue and pull request templates.
- A signed [Contributor License Agreement](https://github.com/palcode/opendronelab/blob/main/CLA.md) is required (Harmony HA-CLA-I v1.0).
- Questions belong in Q&A. Ideas and experiments belong in Ideas or Show and tell. Please do not use issues for support questions once those categories are open.

## House rules

- Do not loosen regression gates.
- Do not add secrets, hostnames, or personal paths to the repository.
- Follow the [Code of Conduct](https://github.com/palcode/opendronelab/blob/main/CODE_OF_CONDUCT.md).
- Security reports go through [SECURITY.md](https://github.com/palcode/opendronelab/blob/main/SECURITY.md), not a public issue.

We are building in public. If you want to help, the roadmap issues and good first issues are the best place to start.
