# Contributing

Contributions are welcome under [CONTRIBUTING.md](https://github.com/palcode/opendronelab/blob/main/CONTRIBUTING.md) and the [Code of Conduct](https://github.com/palcode/opendronelab/blob/main/CODE_OF_CONDUCT.md).

## Start here

- Pick up a [good first issue](https://github.com/palcode/opendronelab/labels/good%20first%20issue).
- Please use the issue and pull request templates.
- A signed [Contributor License Agreement](https://github.com/palcode/opendronelab/blob/main/CLA.md) is required (Harmony HA-CLA-I v1.0, outbound Option Five). Signatures are recorded on the `cla-signatures` branch, not on `main`.

## House rules

- Do not loosen regression gates.
- Do not add secrets, hostnames, or personal paths to the repository.
- Questions will go to GitHub Discussions once the maintainer enables them. A welcome post draft lives in `docs/community/welcome-discussion.md` and should not be posted until then.

Automated agents working in the repository must follow [AGENTS.md](AGENTS.md).
