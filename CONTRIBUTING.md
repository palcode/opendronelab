## Contributor License Agreement (required)

A signed Contributor License Agreement (CLA) is required for your
contribution to be accepted. The current text in [CLA.md](CLA.md) is
the official Harmony Individual Contributor License Agreement
(HA-CLA-I) Version 1.0 (4 July 2011), with inbound copyright license
(not assignment) and outbound Option Five: the project may license a
contribution under any license, including copyleft, permissive,
commercial, or proprietary licenses, and must also license it under
the project's license(s) as of the Submission Date. That is what
makes dual AGPL-3.0-only and commercial licensing possible. You keep
your copyright. The official source is
<https://www.harmonyagreements.org/docs/ha-cla-i-v1.pdf>.

**That agreement is not yet in force.** It has not had a lawyer
review. Please do not sign it yet. Two official fill-in fields
(`[JURISDICTION]` and `[LIST_OF_MEDIA_LICENSES]`) are still
placeholders. Pallab will say when a final CLA is approved.

A CLA-assistant GitHub Action is checked in under
`.github/workflows-disabled/` so it can be enabled later. It is
**not** active. It will not be moved into `.github/workflows/` or
turned on until the CLA text is approved.

This project uses a CLA, not a Developer Certificate of Origin (DCO)
sign-off, because dual licensing needs an explicit relicensing grant.

When the CLA is in force, you will typically sign it on a pull request
by posting the comment the CLA assistant requests (the exact wording
will be in the action and in the approved CLA).

## How to contribute

The repository is private today and is not accepting external
contributions until the open-source launch checklist is finished and
the copyright holder publishes the project. When that happens:

1. Open an issue or start from an existing one, unless you are sending
   a small typo or docs fix.
2. Fork the repository (or push a branch, if you have been given
   access) and open a pull request against `main`.
3. Sign the approved CLA when the assistant asks.
4. Keep changes focused. Do not loosen regression gates, and do not
   include secrets, credentials, or machine-specific paths.

Development setup is in [README.md](README.md) and `docs/setup-host.md`.
