# Security Policy

## Disclaimer

OpenDroneLab is a **simulation-first** research and development project.
It is **not flight-certified**, is not an approved aviation product, and
must not be used to operate a real aircraft without separate safety,
legal, and range review, a manual override, and validated failsafes.
Hardware bring-up notes in this repository are placeholders until an
airframe is named and those reviews are complete. See
[docs/real-drone-readiness.md](docs/real-drone-readiness.md).

## Supported versions

Security updates, when any are issued, apply to the current `main`
branch of this repository. Older snapshots are not maintained as
supported releases.

## Reporting a vulnerability

Please report vulnerabilities through GitHub private vulnerability
reporting on this repository:

https://github.com/palcode/opendronelab/security/advisories/new

If that form is not available, contact the maintainer via the GitHub
profile https://github.com/palcode. No email address is published here.

Do **not** file a public issue, a public discussion, or a public pull
request that describes an unfixed vulnerability.

Please include enough detail to reproduce the issue (affected commit
or version, environment, and steps). We will review reports in good
faith and, where appropriate, coordinate a fix and a public advisory
before any disclosure. We do not publish a fixed response-time SLA.

Repository administrators should enable GitHub's "Private vulnerability
reporting" option on this repository so the advisory form works. That
setting does not change repository visibility.
